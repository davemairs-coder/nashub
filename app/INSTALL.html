Install NAS Hub on your own server

This folder is the whole app: plain files, no database. Put them on any web server on your network and open the address in a browser. About 10 minutes.

1. Copy the folder to your NAS

Unzip this download and copy the folder to a share on your NAS, for example /mnt/tank/apps/nashub on TrueNAS. Keep the files together: index.html, sw.js, manifest.json, the two icons, and the agent and help folders.

2. Serve it with a small web server

Docker (any NAS that runs containers): one line. Change the folder path to where you copied it, and 8080 to any free port.

docker run -d --name nashub --restart unless-stopped -p 8080:80 -v /mnt/tank/apps/nashub:/usr/share/nginx/html:ro nginx:alpine

TrueNAS SCALE without the command line: Apps → Discover Apps → Custom App. Image nginx, tag alpine. Add a host path storage from your folder to /usr/share/nginx/html (read only). Port: host 8080 → container 80. Save.

Already have a web server (Nginx, Apache, Caddy, a Synology or Unraid web share)? Point a site at the folder. Nothing else to set up.

3. Open it

  1. On your phone or computer, on your home Wi-Fi, open http://<your NAS address>:8080 (for example http://192.168.1.20:8080).
  2. Add your apps, or import them from TrueNAS (Manage → Add apps → TrueNAS).
  3. Every feature is included. To use Group Sync, short share links or online backup, set up your own sync server (the sync-server folder of the source code) and enter its address under Manage, Sync and backup, Group Sync.
Plain http on your home network works for everything in the app, and it is the setup that can check local addresses like http://192.168.x.x. Two things browsers only allow over https: adding it to the Home Screen as an app, and down alerts on a phone. For those, put it behind https, for example with Tailscale (tailscale serve 8080 on the NAS) or the reverse proxy you already use.

4. Update to a new version

  1. Download the new zip from your account and unzip it.
  2. Replace the files in the folder on your NAS with the new ones. Your apps and settings are kept: they live in each browser, not in these files.
  3. Open NAS Hub. It shows "New version ready"; tap it. If it doesn't, close the tab and open it again.

Help

help/NASHUB-AI-HELP.md explains every screen and the common walls (why some checks say BLOCKED, the TrueNAS bridge, alerts). You can paste it into an AI assistant and ask your question.

Still stuck? Open an issue on the project page (in the app: Manage, About, Get the code) with the version shown next to the NAS Hub name.
